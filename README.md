# 🌳 বংশ পরম্পরা ও পারিবারিক ইতিহাস (Family Tree) - Mobile First Edition

আপনার পারিবারিক বংশলতিকা মোবাইল ফ্রেন্ডলি ও ইন্টারঅ্যাক্টিভ উপায়ে সবার কাছে তুলে ধরার জন্য তৈরি একটি আধুনিক ওয়েব অ্যাপ্লিকেশন।

---

## 📱 মোবাইল ফোকাস জার্নি (Mobile-First Experience)

অধিকাংশ মানুষ ফোন দিয়ে বংশলতিকা দেখবে বিধায় এটি বিশেষভাবে মোবাইলের জন্য অপ্টিমাইজ করা:

1. **ফোকাসড হিরো কার্ড (Focused Hero Card):**
   - সাইটে ঢুকলেই প্রথমে আদিপুরুষ **পরানউল্লা**-এর পূর্ণাঙ্গ প্রোফাইল কার্ডটি চমৎকারভাবে প্রদর্শিত হয়।
   - এতে তার বড় ছবি/অবতার, বাসস্থান (বানিশান্তা গ্রাম) এবং ঐতিহাসিক নোট সুন্দর বাক্সে দৃশ্যমান থাকে।
2. **সন্তানদের ইন্টারঅ্যাক্টিভ লিস্ট (Children Flow):**
   - কার্ডের ঠিক নিচেই তার সন্তানগণ (হাজী আমানউল্লা, দরাজউল্লা, শরাফউল্লা) সুন্দর ট্যাপ-যোগ্য কার্ড আকারে দেখা যায়।
   - যেকোনো সন্তানের ওপর ট্যাপ করলেই চমৎকার মসৃণ অ্যানিমেশনে সেই ব্যক্তি মাঝখানে মূল কার্ড হয়ে চলে আসে এবং নিচে তার সন্তানরা চলে আসে!
3. **পূর্বপুরুষের ব্রেডক্রাম্বস (Ancestor Breadcrumb Navigation):**
   - উপরে সবসময় ট্রেইল দেখা যায় (যেমন: `পরানউল্লা › হাজী আমানউল্লা › হাজী ইমদাদ আলী › আফেল উদ্দিন › তানভীর`)। যেকোনো নামে চাপ দিয়ে সেকেন্ডেই আগের প্রজন্মে ফিরে যাওয়া যায়।
4. **ডুয়াল ভিউ (মোবাইল ফোকাস বনাম ফুল ট্রি ম্যাপ):**
   - **📱 ফোকাস:** মোবাইলের জন্য নিখুঁত ধাপ-ভিত্তিক ভিউ।
   - **🗺️ ফুল ট্রি:** সম্পূর্ণ বংশবৃক্ষ এক ক্যানভাসে দেখার সুবিধা।
